# xv6_ssu_slab_sched

xv6 커널에 실시간 스케줄링 클래스와 메모리 할당자를 추가한 개인 프로젝트입니다.

## 구현한 것

### 1. 실시간 스케줄링 클래스와 기아 방지
- `fork_rt(priority)` 시스템 콜로 실시간(RT) 프로세스를 생성합니다.
- 스케줄러는 실행 가능한 RT 프로세스 중 우선순위가 가장 높은 것을 먼저 고르고,
  RT 프로세스가 없을 때만 일반 프로세스를 라운드 로빈(RR)으로 실행합니다.
- 이 구조에서는 일반 프로세스가 굶습니다. 일반 프로세스의 우선순위를 올리는
  통상의 aging은 RT가 항상 먼저 선택되므로 효과가 없습니다.
- 그래서 RT 프로세스가 100틱 동안 연속 실행되면 RR로 강등하고,
  5틱 뒤 원래 RT였던 프로세스를 RT로 복귀시킵니다.
  원래 클래스는 `my_rr_rt` 필드에 기록합니다.

### 2. 큰 메모리 할당
xv6는 한 번에 한 페이지(4096바이트)까지만 할당합니다. 두 가지 방식으로 확장했습니다.
- 연속 할당 (`kalloc_large`): 빈 페이지 중 주소가 이어진 것을 찾아 페이지 단위로 할당
- 분해 할당 (`kmalloc`): 요청 크기를 slab 크기들의 합으로 나누어 필요한 만큼만 할당
  (예: 7439바이트 = 2048×3 + 1024 + 256 + 15)

## 수정한 파일

| 파일 | 내용 |
|---|---|
| `src/proc.c` | `fork_rt()`, RT/RR 스케줄러 |
| `src/trap.c` | 타이머 인터럽트에서 강등과 복귀 처리 |
| `src/proc.h` | `rt_rr`, `my_rr_rt`, `aging_time` 필드 |
| `src/kalloc.c` | `kalloc_large()` |
| `src/[slab 파일명]` | slab 할당자, `kmalloc()` / `kmfree()` |
